# 07 · Keep it clean (optional)

**Changes your mailbox:** Only labels for senders you already decided on.

## Prompt

```
Set up a weekly scheduled task every Sunday morning that:
- scans the past 7 days of Gmail (read-only first)
- applies my existing labels to new mail from senders I already decided on
- lists NEW senders with 3 or more emails that week, with a suggested group
  and action
- updates the Inbox Triage Board with the new counts
It must not archive, trash, mark spam or unsubscribe without asking me.
```

## Permanent filters

The Gmail connector can label mail but cannot create Gmail filters. For a filter that sorts mail the moment it arrives, use the dashboard's **Copy Gmail search** button, paste it into Gmail's search bar, open the search options and choose **Create filter**.
