# 09 · Keep it clean 🧹

> **Changes Gmail?** Labels and tabs only, and only for senders you already decided on.

## Prompt (Claude does a weekly check)

```
Set up a weekly scheduled task every Sunday morning that:
- scans the last 7 days of my Gmail (read-only first)
- applies my existing labels and tabs to new mail from senders I've already
  decided on
- lists NEW senders with 3+ emails that week, with a suggested group
- lists anything that landed in Primary but looks like an ad or newsletter
It must not delete, archive, mark spam or unsubscribe without asking me.
```

## Or: no Claude needed

Install the [TabTidy script](../docs/path-2-script-and-filters.md). It runs inside your own Google account on a schedule you pick and needs no one to check in.
